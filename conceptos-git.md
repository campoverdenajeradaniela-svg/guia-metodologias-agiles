**1. Introducción**
Git es un sistema de control de versiones distribuido utilizado en el desarrollo de software. Permite registrar, gestionar y controlar las modificaciones realizadas en los archivos de un proyecto.

**2. Funciones principales de Git**
Git permite mantener un historial de los cambios, recuperar versiones anteriores, comparar modificaciones, trabajar en equipo y desarrollar nuevas funcionalidades mediante ramas independientes.

**3. Control de versiones**
El control de versiones es un sistema que registra y gestiona los cambios de un proyecto a lo largo del tiempo. Permite consultar modificaciones, recuperar versiones anteriores y evitar la pérdida de información. Existen tres tipos: local (almacena las versiones en el ordenador), centralizado (utiliza un servidor central) y distribuido (cada usuario dispone de una copia completa del repositorio y su historial). Git utiliza el sistema distribuido.

**4. Diferencia entre Git y GitHub**
Git es la herramienta que permite controlar las versiones y gestionar los cambios de un proyecto. GitHub es una plataforma online que permite alojar repositorios Git, compartir proyectos y colaborar con otros desarrolladores.

**5. Comandos básicos de Git**

| Comando      | Descripción                                            |
| ------------ | ------------------------------------------------------ |
| `git init`   | Inicializa un nuevo repositorio Git.                   |
| `git clone`  | Descarga una copia de un repositorio existente.        |
| `git add`    | Prepara los cambios para registrarlos.                 |
| `git commit` | Guarda los cambios preparados en el historial local.   |
| `git push`   | Envía los commits al repositorio remoto.               |
| `git pull`   | Descarga e integra los cambios del repositorio remoto. |
| `git branch` | Permite crear y consultar ramas de desarrollo.         |


**6. Funcionamiento básico**
El proceso habitual consiste en modificar los archivos, utilizar `git add` para preparar los cambios, ejecutar `git commit` para registrarlos en el historial y utilizar `git push` para subirlos al repositorio remoto. Para obtener las modificaciones realizadas por otros usuarios se utiliza `git pull`.

**7. Conclusión**
Git es una herramienta esencial en el desarrollo de aplicaciones, ya que facilita el control de versiones, la organización de proyectos y el trabajo colaborativo. Sus comandos permiten gestionar las modificaciones de forma organizada y mantener actualizado el código fuente.
